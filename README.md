# ForexBid HTML demo

Static browser preview of ForexBid, a peer-to-peer FX bidding marketplace. No backend, database, or real payments — forms only move between screens.

**Stack:** HTML, CSS, JavaScript, [Tailwind CSS](https://tailwindcss.com) (CDN).

Open `index.html` locally, or run `python -m http.server 4173`. Import this repo on Vercel with framework **Other** and an empty build command.
